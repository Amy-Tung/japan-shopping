# 炭寶代購團｜日本購物小清單

讓朋友填入訂購人姓名與想買的商品，估算台幣金額並複製明細。

## 分區與功能

- 訂購人姓名會一起放入明細；複製前需要填寫姓名。
- 日幣填每件商品含稅單價；數量為選填，預設 1，留白亦視為 1。先計算單價 × 數量，再加總。
- 新舊清單都使用固定代購匯率 0.23，不另加 10%，也不自動讀取銀行匯率。
- 所有清單的整筆台幣四捨五入到整數元。
- 既有瀏覽器清單開啟新版時按現行固定匯率重新計價；「清除內容」會清空姓名及商品。已複製或傳出的舊報價不會自動更新。
- 「訂購清單」區編輯訂購人與商品，顯示日幣總計與換算台幣；可使用日幣或台幣付款。
- 「訂購單預覽」區自動呈現完整唯讀訂購單；無文字編輯控制，所有調整都在第一區進行。複製文字的金額合計包含代購匯率。
- 唯讀訂購單隨清單即時更新，複製成功提示明顯；不支援剪貼簿時可選取訂購單文字手動複製。
- 匯入不要求固定標題、總計或範本。支援常見自由描述、中文數量、貨幣符號、單價標記、CSV/TSV 欄位與舊版本明細；直接追加商品，不取代、不預覽。成功提示在商品清單區。
- 系統辨識為金額的數字均視為日幣，不依符號轉換其他幣別。
- 價格未知或未填的商品保留，先加總已填價格的商品；金額區與複製訂購單都提醒尚未計價的商品列數。全部價格未知時，顯示待補價格而非免費。
- 本地辨識是規則式、盡力解析，不是無限制的語意理解。每行一項商品；辨識後可在第一區修正。不能辨識的描述仍可作為待補價格商品。價格為整數日幣；不會把小數價格截掉。
- 若目前姓名為空，匯入時會帶入明細中的姓名；已有姓名則保留。
- 清單只保存於目前瀏覽器的 localStorage，不會上傳訂購人或商品資料。

## 視覺與分區

沿用既有炭寶黑貓圖像，搭配奶油紙色、朱紅與日式文具風格。介面固定分為「訂購清單」及「訂購單預覽」兩個區域；支援行動裝置與深色模式。

## 固定匯率

代購匯率固定為 0.23，不自動隨銀行牌告變動。價格由日幣合計乘以 0.23，整筆四捨五入到整數台幣。
